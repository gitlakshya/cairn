QUICK START (5 Minutes)
───────────────────────────────────────────────────────────────────────────

1. Install:
   npm install
   npm run build

2. Initialize (in your repository):
   node /path/to/dist/index.js --init

3. Configure Claude Code:
   Add to ~/.claude.json:
   {
     "mcpServers": {
       "repository-context": {
         "command": "node",
         "args": ["/absolute/path/to/dist/index.js", "--mcp"]
       }
     }
   }

4. Restart Claude Code
   Done! Context server is now available.
